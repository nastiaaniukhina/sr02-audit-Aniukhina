## Чому відмова

- D-05 (R12): у Seed категорія `"Student"` не збігається з `"student"`. Заміна рядка на enum чи Value Object змінила б поведінку для читачки R-1006 (вона отримала б 30 днів замість 14). Ризик високий, а виправлення помилки це окремий `fix`.
- D-12 (R19): `Issue(…, bool readingRoom)` викликається з Program і з тестів. Зміна сигнатури змусила б чіпати тести без зміни очікуваних значень.

## Правила безпеки

1. Один рефакторинг, один коміт. Змішувати з виправленням помилок заборонено.
2. Крок довший за 20 хвилин розбивається на менші.
3. Після кожного кроку `dotnet build` і `dotnet test`.
4. Якщо тести червоні понад 10 хвилин, `git checkout .` і починаю крок спочатку меншими порціями.
5. Спочатку кроки з низьким ризиком.
6. Файли тестів не змінюю; очікувані значення не змінюю ніколи.
7. Після кожного кроку записую хеш коміта й тривалість у хвилинах (для розділу 7).
